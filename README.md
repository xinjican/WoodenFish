# 🪵 WoodenFish

> Clear your mind, accumulate merits. A minimalist Zen Wooden Fish Android app built with modern Jetpack Compose.

## ✨ Features

- ⚡ **Zero-Latency Audio**: Powered by Android's game-grade `SoundPool` for ultra-responsive percussion clicks without dropping beats.
- 📳 **Tactile Haptic Feedback**: Integrated with hardware `Vibrator` to deliver a realistic strike sensation on every tap.
- 🎨 **Spring Physics Animation**: Responsive bounce animation with floating, fading "+1 Merit" indicator.
- 🖤 **Zen Aesthetic Visuals**: Crisp, handcrafted Vector Drawable maintaining sharp fidelity on all screen densities.
- 📱 **Native 64-Bit Architecture**: Built with full `arm64-v8a` support for modern Android devices.
