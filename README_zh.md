## ✨ 特性亮点

- ⚡ **零延迟清脆音效**：采用 Android 游戏级音频池 `SoundPool`，毫秒级快速响应，连敲绝不吞音。
- 📳 **真实触感微震动**：深度集成系统底层 `Vibrator` 马达反馈，每一次敲击都伴随逼真触感。
- 🎨 **物理回弹动效**：基于物理弹簧（Spring）的微缩放与「功德 +1」平滑浮空淡出动画。
- 🖤 **沉浸式黑金禅意美学**：精心绘制的温润金丝木鱼矢量图（Vector Drawable），无惧高分屏失真。
- 📱 **纯正 64 位架构**：原生支持 `arm64-v8a`，全面兼容现代安卓旗舰手机。

* **开发语言**：Kotlin
* **UI 框架**：Jetpack Compose (Material 3)
* **音频引擎**：Android SoundPool
* **构建系统**：Gradle (Kotlin DSL)
